Approach

How I build

Cheap signals gate expensive ones

Free checks like titles, DNS records and redirects run first, so scraping, enrichment and AI calls only happen on records that earned them.

Rules first, AI for the grey zone

Pattern matching handles the clear cases. AI gets the ambiguous ones with a structured evidence bundle, and its calls are logged so they can become rules later.

Design before code

I settle triggers, data sources, failure modes and hosting on paper before writing the first line. It keeps the build short.

Built for the person on the call

The output lands where sellers already are: a Slack brief, a sheet, a drafted email. If a rep has to open a new tool, it won't get used.
